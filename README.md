# Infraestrutura

Repositório de estudos e experimentos relacionados a **infraestrutura**, voltado ao aprendizado e organização de conceitos na área (por exemplo: redes, sistemas, automação, containers, provisionamento, entre outros). Este repositório serve como base para consolidar seu conhecimento sobre ferramentas e estratégias de infraestrutura.

## Objetivo

- Organizar meu conhecimento e aprendizado sobre infraestrutura.
- Registrar scripts e configurações testadas em laboratório ou ambiente real.
- Criar uma base que possa ser reutilizada ou compartilhada futuramente.
